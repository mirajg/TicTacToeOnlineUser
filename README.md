# Real-Time Tic-Tac-Toe (Next.js + Socket.io)

A simple multiplayer Tic-Tac-Toe game where two users can play against each other in real-time.

## Project Architecture

* **Frontend:** Next.js (React)
* **Backend:** Node.js + Express
* **Real-time Communication:** Socket.io
